# Анализ социально-экономических и медицинских показателей

## Описание проекта
Репозиторий содержит программное решение для сбора, предобработки, хранения и визуализации статистических данных. Проект реализует полный цикл работы с данными (Data Pipeline): от автоматизированного парсинга открытых данных портала Мосстата до проектирования реляционной базы данных, разработки сервиса для управления данными и построения интерактивного дашборда в BI-системе.

## Цели и задачи
**Цель проекта:** Разработка информационной системы для автоматизированного сбора, анализа и визуализации ключевых социально-экономических и медицинских показателей г. Москвы.

**Задачи:**
1. **Сбор данных:** Реализация парсера для извлечения данных с сайта Мосстата по показателям: динамика ИПЦ, денежные доходы населения, уровень бедности, заболеваемость по основным классам болезней, численность медицинских кадров.
2. **Предобработка и анализ (EDA):** Проведение разведочного анализа с построением графиков в Jupyter Notebook (библиотеки `matplotlib`, `seaborn`), выявление трендов и написание аналитических выводов.
3. **Проектирование хранилища:** Разработка схемы и создание таблиц в реляционной базе данных PostgreSQL для структурированного хранения очищенных показателей.
4. **Разработка сервиса:** Создание программы, объединяющей этапы ETL: автоматическое скачивание, предобработка, загрузка в БД и предоставление данных пользователю по запросу (например, выдача численности мед. кадров за конкретный год).
5. **Визуализация:** Подключение BI-системы Cubisio к базе данных и создание интерпретируемого дашборда с набором диаграмм для мониторинга динамики и структуры исследуемых показателей.
